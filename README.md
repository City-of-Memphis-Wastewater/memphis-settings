# memphis-settings

Manage encrypted secrets, plaintext configs, and .env settings locally.

## memphis-secret

Two-key encrypted AES-256 local value store.

## memphis-config

Two-key plaintext local value store.

## memphis-env

CRUD for .env file in package root.
